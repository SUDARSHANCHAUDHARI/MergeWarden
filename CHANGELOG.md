## [0.1.0] - 2026-08-12

### Added

- Profile-aware GitHub identity and repository allowlists.
- Read-only repository and PR inventory.
- Explicit candidate-branch PR creation with verification commands and secret-pattern checks.
- Targeted PR readiness checks and guarded squash, merge, or rebase operations.
- Personal auto-merge policy and approval-gated work policy.
- Branch preservation by default with explicit deletion opt-in.
- Read-only scheduled scans with explicit scheduled mutation opt-in.
- JSONL mutation audit records.
- Codex skill and Claude Code command adapters.
- Unit and fake-CLI integration tests for safety-critical behavior.
